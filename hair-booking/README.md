# Tóc Studio — сайт записи на наращивание волос (Хошимин)

Сайт для мастеров по наращиванию волос: клиенты видят свободные окошки в календаре и оставляют заявку, мастера отмечают окошки и обрабатывают заявки в закрытой панели.

- **Сайт для клиентов** (`/`): услуги и цены в донгах, мастера, календарь свободных окошек, форма заявки. Три языка: русский, английский, вьетнамский.
- **Панель мастера** (`/admin`): вход по паролю, календарь окошек, добавление окошек сразу на период («с 14 по 31 октября, вт/чт/сб, 10:00 и 15:00, по 3 часа»), удаление, список заявок с кнопками «Подтвердить» и «Отменить».
- **Уведомления в Telegram** о каждой новой заявке (по желанию).

Окошко закрепляется за клиентом сразу после заявки, второй человек записаться на то же время не сможет. Если мастер отменяет заявку, окошко снова появляется на сайте.

## Запуск на компьютере

Нужен только Node.js 18 или новее, больше ничего устанавливать не надо.

```bash
cd hair-booking
ADMIN_PASSWORD=придумайте-пароль npm start
```

Откройте http://localhost:3000, панель мастера — http://localhost:3000/admin.

Чтобы посмотреть сайт с примерами окошек и заявок: `ADMIN_PASSWORD=test npm run demo`. Демо-данные записываются в `data/db.json`; на рабочем сайте эту команду не запускайте.

## Что поменять под себя

Всё содержимое сайта — в файле `config.json`:

- `salon.name` — название студии;
- `salon.area`, `salon.addressNote`, `salon.hours` — район, примечание про адрес, часы работы (на трёх языках);
- `salon.contacts` — телефон, Zalo, Telegram, WhatsApp, Instagram. Пустые поля на сайте не показываются;
- `masters` — мастера: `id` (латиницей, не менять после запуска), имя, специализация, стаж;
- `services` — услуги: название, описание, длительность в минутах, цена «от» в донгах (`0` — бесплатно);
- `lengths` — варианты длины в сантиметрах для формы.

Тексты интерфейса — в `public/js/i18n.js`. После правок перезапустите сервер.

## Настройки (переменные окружения)

| Переменная | Что делает |
|---|---|
| `ADMIN_PASSWORD` | Пароль панели мастера. Без него сервер придумает временный и покажет его в консоли. |
| `PORT` | Порт, по умолчанию `3000`. |
| `DATA_DIR` | Папка с окошками и заявками, по умолчанию `./data`. |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Уведомления о заявках в Telegram. |
| `TRUST_PROXY=1` | Включите, если сайт стоит за Nginx, Caddy или облачным балансировщиком. |

### Уведомления в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и получите токен бота.
2. Напишите своему боту любое сообщение (или добавьте бота в общий чат мастеров).
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}` — это `TELEGRAM_CHAT_ID`. У групп он начинается с минуса.
4. Запустите сервер с `TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...`.

## Размещение в интернете

Сайту нужен сервер, который не «засыпает» и сохраняет файлы между перезапусками: все окошки и заявки лежат в `DATA_DIR/db.json`.

**VPS (самый простой и дешёвый вариант, от $5 в месяц).** Подойдёт любой: DigitalOcean, Hetzner, Vultr и т. п.

```bash
# на сервере
git clone <ваш репозиторий> && cd <репозиторий>/hair-booking
npm install -g pm2
ADMIN_PASSWORD=... TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... TRUST_PROXY=1 pm2 start server.js --name hair
pm2 save && pm2 startup
```

Для домена и HTTPS поставьте перед сайтом [Caddy](https://caddyserver.com) — в `Caddyfile` хватит двух строк:

```
ваш-домен.com
reverse_proxy localhost:3000
```

**Docker** (Railway, Fly.io, Render с постоянным диском и т. п.): в папке есть `Dockerfile`, данные хранятся в `/data` — подключите туда постоянный том (volume), иначе заявки пропадут при перезапуске.

```bash
docker build -t hair-booking .
docker run -d -p 3000:3000 -v hair-data:/data -e ADMIN_PASSWORD=... hair-booking
```

### Резервная копия

Достаточно время от времени копировать файл `data/db.json`.

## Как устроено

- `server.js` — сервер без внешних зависимостей: API, раздача страниц, вход в панель (подписанная cookie на 14 дней), защита от повторной записи, ограничение частоты заявок и попыток входа.
- `public/index.html`, `public/js/app.js` — сайт для клиентов.
- `public/admin.html`, `public/js/admin.js` — панель мастера.
- `public/js/calendar.js` — календарь, общий для обеих страниц.
- Время окошек хранится по Хошимину (`Asia/Ho_Chi_Minh`), поэтому клиент из другой страны видит то же время, что и мастер.
