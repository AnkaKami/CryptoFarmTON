# Собачья жизнь / One Dog's Life

Ты рождаешься случайной собакой из ~900 миллионов и проживаешь её жизнь. Примерно 3 из 4 собак в мире живут свободно, на улицах и в деревнях, поэтому чаще всего выпадает улица.

- `game.html` — исходник игры. Один файл: HTML, CSS и JS без зависимостей, только шрифты Google Fonts.
- `index.html` — готовая страница для любого статического хостинга. Собирается командой `node dog-life/build.js`.

## Что внутри

- Лотерея «из 100 щенков»: улица, деревня, дом, цепь, ферма-питомник, служба, приют.
- 23 страны, 23 породы, процедурный портрет собаки (рисуется на canvas).
- Примерно 60 событий с выбором. Есть смена судьбы: дом за границей, приют, потеряшка.
- Причины смерти зависят от условий жизни, возраста и породы.
- Карточка собаки 1080×1350 для шеринга (Web Share API), кнопка копирования текста.
- «Стая»: архив прожитых жизней в localStorage.
- Русский и английский языки, светлая и тёмная темы.

## Данные

- Около 3/4 собак живут свободно (оценка WOAH, по обзорам).
- Около 19% уличных щенков доживают до взрослого возраста (Paul et al., 2016, Sci Rep, Индия).
- Остальные вероятности — упрощённая модель. Перед релизом её стоит уточнить.
